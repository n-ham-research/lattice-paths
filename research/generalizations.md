# Candidate generalizations

These are research directions, not novelty claims or manuscript results.

- Residue layers: for q≥1 integer and vertical increments qZ in the triangle, complete-layer products give (m!)^q(m+1)^s at column n=qm+s, 0≤s<q. For a nonzero residue a mod q, reachable height residue is na; early empty layers can annihilate all subsequent counts. Check exact reachability rather than only congruence.
- Nested finite height sets H_0={0}⊆H_1⊆... with all nonzero jumps: total at layer n is ∏_(j=1)^n(|H_j|−1). Existing endpoint count is previous total minus its previous count. This permits alternating products. The source wedges are special cases; see independent-initial-audit.md for complete derivation and a proposed signed involution.
- Constant predecessor counts per block preserve within-block uniformity and yield finite matrix products. Initial uniformity within blocks is essential; the singleton origin or a compatible initial partition supplies it.
- A classification of actual translation-defined step sets and boundaries that produce such regular blocks would have more content than the generic matrix identity. Literature comparison remains required.
- Walk categories and additive constrained languages are already suggested by East–Ham (Remark 3.4/Lemma 3.2); future algebraic claims should explain counts, rather than restating closure properties.
