# Phase 2 mathematical summary (historical snapshot)

Current Phase 4 results and limitations are in [handover-phase4.md](handover-phase4.md); the discussion briefing is [../briefing/main.tex](../briefing/main.tex). The text below preserves the Phase 2 state and its original theorem numbering.

Nicholas Ham — working research, 16 October 2026. This note is prepared for possible later sharing; nobody has been contacted and no collaboration is assumed.

**Main structural result.** Fix q≥1 and a vertical jump set D⊆Z. On triangular layers I_n={0,...,n}, let T_n send p(z) to Σ_z 1_D(y−z)p(z). For N≥q, every transition through N preserves *every* vector constant on residues modulo q if and only if 1_D is q-periodic on the exact observable window [1−N,N]. Hence all triangular transitions have this property precisely when D is a union of full residue classes. This classifies a transition invariant space, not accidental uniformity of one origin's path counts. The converse uses comparisons of consecutive growing source intervals to recover individual jump indicators. Full proof: phase2-classification.md and manuscript Theorem4.2. Limited searches have not resolved priority; the result may be too narrow to carry a paper alone.

**Moving intervals.** If a source residue cell has endpoints a_r,b_r, incoming residue regularity for an arbitrary target interval is equivalent to 1_D(y−a_r+q)=1_D(y−b_r) whenever y,y+q are target vertices. This telescoping boundary criterion is exact and includes empty cells. It identifies what moving boundaries must preserve; broad geometric classification remains open.

**Explicit classical bijections.** Reverse and negate a nonnegative excursion over +1 and −a, append −1, and read increment+1 as preorder degree. This gives a plane tree and, by degree-to-up-run expansion, a Dyck path with ascents in A+1. The inverse and size statistics are explicit. It unifies the source restricted-ascent and several tree models. Composing with classical polygon duality proves that §18 paths of lengthN correspond to even-faced polygon dissections with N+1 total edges, including a separately formal empty-object convention. The two §17 Fuss models have the same horizontal-coordinate axis series, though different total word lengths. These are applications of known constructions, not claimed novel bijections.

**Historical and correction evidence.** East–Ham v1 Example3.14 already proves substantial factorial material omitted from v3. The remaining audit finds false unrestricted and asymmetric-source claims, and resolves others by exact composition formulas. All697 printed values of the ten original arrays match independent DP; two axis labels require correction. Source words, corrected formulas, numeric evidence and first-priority questions are tracked separately.

**Assessment.** The package now has a genuine proved structural converse beyond factorial induction and useful unifying bijections. It is suitable as a precise exploratory discussion package, but not yet a submission-ready claim of original mathematics. The highest-value next step is to determine whether rigidity extends to natural moving windows or more general partitions in a way that is both new and useful. A second direction is direct object-level bijections for the remaining polygon/blob/packed-word identifications, retaining East–Ham's word-category data rather than only endpoint monoids.
