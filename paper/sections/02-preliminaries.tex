\section{Preliminaries}
A path is a finite word in a step set $S\subseteq\Z^2$, with partial sums beginning at $(0,0)$. It is admissible in a region $R$ when all partial sums lie in $R$. We count the empty word once. The regions used below are convex, so requiring whole segments to remain in the region gives the same condition. Step sets have no multiplicities.

All models proved here have horizontal increment one. Write $P_n(y)$ for the number of admissible paths to $(n,y)$ and $T_n=\sum_yP_n(y)$. Their finite columns make these counts finite despite infinite step sets. Unreachable endpoints have count zero. These conventions are not imposed on every model in the original collection, some of which have vertical steps.
